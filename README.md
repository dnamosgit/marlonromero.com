# Marlon Romero Gomez — portfolio

Static site (no build step). Open `index.html`, or serve the folder with any static host.

- `js/data.js` — all content to fill in: artworks, hero/portrait images, exhibitions, contact details, form endpoint.
- `images/` — put the original, unmodified painting files here and reference them from `js/data.js`.
- Gallery categories: `gallery.html?c=landscapes | visionary | still-life | murals`.
